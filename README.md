# КЭШ.СТРИМ (CashStream)

**Веб-игра в жанре "продуктивный кликер" с элементами симулятора жизни фрилансера, выполненная в эстетике Windows 95.**

Вы — фрилансер-стартапер, начинающий путь с дешевым ноутбуком в антикафе. Ваша цель — построить финансовую империю, кликая по рабочим задачам, управляя ресурсами «Фокус» и «Кэш», балансируя на грани выгорания и вкладывая заработанное в биржу и недвижимость.

> **Текущая версия: 0.2.0** (Кликер + Квесты + Казино + Экономика/Инвестиции + Рабочий стол с окнами-программами)
>
> Игра реализована как **Chrome-расширение (Manifest V3)** с общим состоянием через `chrome.storage.local`, что позволяет играть и в попапе, и в полноэкранном режиме без потери прогресса.

---

## 🧠 Главная концепция

Главный ресурс игры — **«Фокус»** (энергия кликов) и **«Кэш»** (игровая валюта). Но вместо скучного кликанья, вы «тапаете» для выполнения реальных рабочих задач. Механика **«Тап-Таска»** визуализирует на экране проекты, а ритмичные клики активируют режим **«Поток»** с комбо-множителем.

Игрок не может просто бесконечно копить кэш в простое: каждые 30 секунд прилетает **счёт за аренду офиса**, который растёт вместе с уровнем. Если денег не хватает — образуется **долг под проценты** и растёт выгорание. Это заставляет активно зарабатывать, а не залипать на пассивном ожидании.

**Итоговый цикл игры:**
1.  **Работайте** — выполняйте квесты, кликая по задачам и зарабатывая Кэш.
2.  **Отдыхайте** — снимайте накопившееся «Выгорание» в мини-играх казино.
3.  **Инвестируйте** — покупайте акции на бирже «Рынок Айти» и объекты недвижимости для пассивного дохода.
4.  **Прокачивайтесь** — нанимайте стажеров, покупайте оборудование и кофемашину, чтобы каждый клик и каждая минута простоя были эффективнее.
5.  **Платите по счетам** — аренда офиса не ждёт, поэтому бездействие обходится дорого.

## 🕹️ Реализованный геймплей

### 1. Симуляция рабочей деятельности (Кликер)
- **Рабочая зона:** Кликайте в центре экрана, чтобы зарабатывать Кэш. Каждый клик тратит «Фокус» и накапливает «Выгорание».
- **Режим «Поток»:** Серия быстрых кликов (быстрее ~0.9 с) активирует комбо-множитель до **x3** к заработку.
- **Выгорание:** При заполнении шкалы до 100% клики блокируются. Единственный выход — посетить казино «Перерыв» для сброса стресса.
- **Пассивный доход:** Наймите виртуальных стажеров, которые приносят Кэш каждую секунду, даже когда вы не кликаете.
- **Апгрейды рабочего места:** «Оборудование» повышает ценность клика, «Кофемашина» снижает затраты фокуса за тап — растущая по цене прогрессия, которая даёт смысл тратить накопленный кэш.

### 2. Мини-квесты (Сюжетные цепочки)
Каждый квест — история из 3 шагов: `tap` (набрать N кликов), `find` (найти ❌ в сетке 3×3), `puzzle` (собрать цены по возрастанию). Прогресс квестов сохраняется между сессиями.

### 3. Симулятор Казино («Перерыв»)
Слот «Деловая встреча» и рулетка «Биржа»: снимают «Выгорание» и позволяют быстро (но рискованно) заработать.

### 4. 📈 Экономика и инвестиции (новое)
- **Биржа «Рынок Айти»:** 5 вымышленных IT-бумаг с ценами, которые «дышат» каждую секунду (случайное блуждание + редкие резкие новости ±10–28%). Можно покупать/продавать лотами 1/5/10/25 акций; каждая сделка облагается комиссией брокера 1%. Мини-график (спарклайн) показывает динамику цены за последние ~28 тиков.
- **Недвижимость:** 4 типа объектов (студия → офис → коворкинг → бизнес-центр), каждый даёт пассивный доход в секунду за вычетом содержания. Цена следующего объекта того же типа растёт.
- **Аренда офиса:** обязательный расход каждые 30 секунд, растёт с уровнем игрока. Нет денег — долг с процентами и штраф к выгоранию, пока не расплатитесь (автосписание идёт из свободного кэша).

### 5. 🖥️ Рабочий стол с окнами-программами (новое)
Полноэкранный режим (`fullpage.html`) теперь настоящий Windows 95-рабочий стол:
- Значки **«Задачи.exe»**, **«Работа.exe»**, **«Перерыв.exe»**, **«Инвестиции.exe»** — двойной клик открывает соответствующую программу как отдельное окно.
- Окна можно **перетаскивать** за заголовок, **сворачивать** (_), **разворачивать на весь экран** (▢) и **закрывать** (×).
- Открытые/свёрнутые окна отображаются кнопками в **таскбаре** — клик по кнопке переключает фокус/восстанавливает окно.
- «Задачи», «Работа» и «Перерыв» открыты по умолчанию (как в старой раскладке), «Инвестиции» — по запросу, чтобы не перегружать экран.

## ⚙️ Как запустить

1.  Откройте в браузере Chrome страницу `chrome://extensions`.
2.  Включите **«Режим разработчика»** (переключатель справа вверху).
3.  Нажмите **«Загрузить распакованное расширение»** и выберите корневую папку проекта `cashstream/`.
4.  В панели расширений появится иконка **«$»**. Нажмите на неё, чтобы открыть попап-версию.
5.  В попапе нажмите **«🖥️ Развернуть на весь экран»**, чтобы попасть на рабочий стол, или сразу откройте **«📈 Инвестиции»** / **«🎰 Перерыв»**.
6.  На рабочем столе дважды кликните по значку `.exe`, чтобы открыть нужную программу.

> **Важно:** Кошелёк, Фокус, Выгорание, Квест, портфель акций и недвижимость — общие для попапа, вкладки и всех открытых окон. Всё состояние хранится в `chrome.storage.local`.
