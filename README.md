# 💰 КЭШ.СТРИМ — Симулятор фрилансера в стиле Windows 95

> «Зарабатывай, пока не выгорел. Или пока не разбогател.»

## 📖 Описание

**КЭШ.СТРИМ** — это кликер / симулятор жизни фрилансера, выполненный в ностальгическом стиле Windows 95. Вы управляете своим персонажем, выполняете задания, зарабатываете деньги, вкладываете их в развитие и стараетесь не выгореть от переработок.

Игра сочетает в себе:
- 🖱️ Кликер-механику с комбо-системой
- 📋 Систему квестов с прогрессией
- 📈 Инвестиции и финансовое планирование
- 🎰 Элементы удачи (казино)
- 🏦 Полноценную банковскую систему
- ⏰ Таймер аренды и систему долгов

---

## 🎮 Игровой процесс

### 🖥️ Рабочий стол
- Все программы запускаются двойным кликом по иконкам
- Окна можно перетаскивать и закрывать
- Панель управления показывает ключевые показатели в реальном времени

### 📊 Основные метрики
| Показатель | Описание |
|-----------|----------|
| 💰 Кэш | Основная валюта, зарабатывается кликами и инвестициями |
| ⭐ Фокус | Влияет на эффективность работы. Восстанавливается отдыхом |
| 🔥 Выгорание | Растёт от работы. При 100% — штрафы |
| 🏠 Аренда | Каждые 30 секунд списывается плата |
| 📈 Комбо | Множитель дохода, растёт при серии успешных кликов |

### 📋 Задачи (Quest.exe)
- Получайте случайные задания с цепочкой шагов
- Типы шагов: клик, поиск, головоломка
- Награда зависит от сложности
- Прокачивайте стажёров и оборудование

### 💻 Работа (Work.exe)
- Активный заработок с механиками:
  - **Клик** — быстро тапайте по кнопке
  - **Поиск** — найдите все элементы на поле
  - **Пазл** — соберите правильную последовательность

### 🎰 Перерыв (Casino.exe)
- Слот-машина для быстрого заработка (или потери)
- Рискните — и удвойте капитал!

### 📈 Инвестиции (Invest.exe)
- Вкладывайте деньги в различные активы
- Пассивный доход с разной доходностью
- Рискованные и надёжные инструменты

### 🏦 Банк (Bank.exe) — НОВИНКА!
Полноценная банковская система:

#### 💰 Депозиты
- Открывайте депозиты с разной процентной ставкой
- Чем дольше срок, тем выше доход
- Досрочное снятие — без процентов
- Пассивный доход каждую секунду

#### 💳 Кредиты
- Быстрые займы для решения финансовых проблем
- Высокие процентные ставки
- Возможность досрочного погашения
- Влияние на кредитный рейтинг

#### 🏠 Ипотека
- Покупка недвижимости в кредит
- Первоначальный взнос от 20%
- Срок до 20 игровых месяцев
- Недвижимость приносит доход сразу

#### 📊 История
- Все финансовые операции в хронологическом порядке
- Цветовая индикация типов операций
- Отслеживание финансового поведения

## 🚀 Установка и запуск

### Требования
- Современный веб-браузер
- Локальный сервер (для корректной работы iframe)

### Быстрый старт

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/cash-stream.git
cd cash-stream

# Используйте любой HTTP-сервер
# Например, с Python:
python3 -m http.server 8000

# Или с Node.js (live-server):
npx live-server
