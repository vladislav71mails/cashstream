# 💰 КЭШ.СТРИМ — симулятор фрилансера в стиле Windows 95

> «Зарабатывай, пока не выгорел. Или пока не разбогател.»

**Версия 0.2.0** · Chrome Extension (Manifest V3) + полноэкранный рабочий стол

## Описание

Кликер / симулятор жизни фрилансера: квесты, инвестиции, банк, казино, налоги, случайные кризисы и выгорание. Интерфейс — ностальгический Windows 95.

## Возможности

- Рабочий стол с окнами, таскбаром и меню **СТАРТ**
- Квесты (клики, поиск, головоломки) и комбо-кликер
- Аренда, долг, мягкий старт и обучение
- Выгорание влияет на успех кликов
- Инвестиции: акции и **дивиденды**, недвижимость, **крипта**, майнинг, **опционы**
- Банк, отчётность (1С / налоги), почта, магазин приложений
- Достижения, случайные события, звуки, boot-анимация Win95
- **Настройка.exe** — звук и параметры загрузки

## Установка

### Как расширение Chrome

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. «Загрузить распакованное расширение» → папка `game/`
4. Popup — по иконке; полный стол — откройте `fullpage.html` через локальный сервер

### Локальный сервер (рекомендуется для fullpage)

```bash
cd game
python3 -m http.server 8000
# откройте http://localhost:8000/fullpage.html
```

Или: `npx live-server` в каталоге `game`.

## Архитектура

```
shared.js          → подключает core/*.js
core/              → ядро CS (конфиг, тик, рынок, события, …)
fullpage.*         → рабочий стол
*.html + *.js      → отдельные «программы» (банк, казино, инвестиции…)
```

Состояние: ключ `csState` в `chrome.storage.local` / `localStorage`.
