# КЭШ.СТРИМ (Cash Stream)
> «Зарабатывай, пока не выгорел или пока не разбогател»
---
**Версия:** 0.3.0  
**Платформа:** Chrome Extension (Manifest V3) + полноэкранный режим (вкладка)  
**Визуальная тема:** Офис 90-х / Windows 95  
---

## 1. Концепция игры

**КЭШ.СТРИМ** — браузерное расширение и симулятор жизни фрилансера в ностальгическом интерфейсе Windows 95.

Игрок управляет «офисным» персонажем: выполняет задания, кликает, инвестирует, берёт кредиты, играет в казино и старается не выгореть от переработок и аренды. Игра сочетает:

- **Кликер** с комбо-системой и расходом фокуса
- **Квесты** (цепочки шагов разных типов)
- **Пассивный доход** (стажёры, депозиты, недвижимость, акции)
- **Риск** (казино, кредиты, волатильный рынок)
- **Менеджмент ресурсов** (кэш, фокус, выгорание, долг, аренда)

Игра работает в двух режимах:

1. **Popup расширения** — компактный вид через иконку в панели браузера
2. **Полная страница** — рабочий стол Windows 95 с иконками программ, перетаскиваемыми окнами и таскбаром

Состояние синхронизируется через `chrome.storage.local` (и fallback на `localStorage`), поэтому прогресс общий между popup, fullpage и отдельными «программами».

## 2. Основные метрики и экономика

| Показатель | Описание |
|-----------|----------|
| 💰 **Кэш** | Основная валюта. Зарабатывается кликами, квестами, инвестициями, депозитами, казино |
| ⭐ **Фокус** | Расходуется при активной работе. Восстанавливается в простое. Влияет на эффективность |
| 🔥 **Выгорание** | Растёт от работы. При высоком значении — штрафы. Снижается отдыхом и «перерывом» в казино |
| 🏠 **Аренда** | Списывается каждые 30 секунд. Растёт с уровнем. Неоплата → долг + выгорание |
| 💳 **Долг** | Накапливается при просрочке аренды / кредитах. Начисляются проценты |
| 🔥 **Комбо** | Множитель дохода за серию быстрых кликов (окно ~900 мс, максимум x3) |
| 📈 **Уровень / XP** | Прогрессия за выполнение шагов и цепочек квестов |

Дополнительные системы:

- **Стажёры** — пассивный доход (кэш/сек)
- **Оборудование** — повышает ценность клика
- **Кофе** — снижает стоимость фокуса за тап
- **Акции («Рынок Айти»)** — волатильные бумаги с комиссией брокера
- **Недвижимость** — покупка, доход, ипотека
- **Банк** — депозиты, кредиты, ипотека, история операций, кредитный рейтинг

## 3. Что реализовано (текущее состояние)

### 3.1. Ядро и инфраструктура

- Manifest V3 расширение (`manifest.json`)
- Service worker (`background.js`)
- Общее ядро состояния и логики (`shared.js`):
  - загрузка/сохранение состояния
  - тики (аренда, долг, фокус, выгорание, рынок, стажёры и т.д.)
  - квесты, клики, комбо, апгрейды, биржа, недвижимость
  - синхронизация между окнами через `chrome.storage.onChanged`
- Единый CSS-фреймворк Windows 95 (`win95.css`)
- Popup-режим и fullpage-режим с рабочим столом

### 3.2. Рабочий стол (fullpage)

- Иконки программ: Задачи, Работа, Перерыв, Инвестиции, Банк, Отчётность, Магазин и др.
- Плавающие окна с перетаскиванием, фокусом, свёрткой в таскбар
- Панель показателей в реальном времени (кэш, фокус, выгорание, аренда, долг, комбо)
- Кнопка «СТАРТ», трей (в т.ч. почта)

### 3.3. Задачи / Квесты (Quest.exe)

- Пул цепочек заданий с несколькими шагами
- Типы шагов: **tap** (клики), **find** (поиск элементов), **puzzle** (последовательность)
- Награды за шаг и за завершение цепочки, XP и прогрессия уровня
- Случайный выбор следующей цепочки

### 3.4. Работа (Work.exe)

- Активный заработок через клики с комбо
- Связь с текущим шагом квеста
- Апгрейды: оборудование (клик-ценность), кофе (экономия фокуса), найм стажёров

### 3.5. Перерыв / Казино (Casino.exe)

- Слот-машина
- Рулетка (canvas)
- Ставки, выигрыши/проигрыши
- Каждый раунд снижает выгорание (официальный «перерыв»)

### 3.6. Инвестиции (Invest.exe)

- Биржа «Рынок Айти» (несколько бумаг с разной волатильностью)
- Покупка/продажа с комиссией
- История цен, новостные скачки
- Недвижимость (покупка объектов, рост цены, доход)

### 3.7. Банк (Bank.exe)

- **Депозиты**: сроки 1 / 3 / 6 / 12 мес., разные ставки, досрочное снятие
- **Кредиты**: займы, проценты, досрочное погашение, влияние на кредитный рейтинг
- **Ипотека**: покупка недвижимости в кредит (первоначальный взнос, срок)
- **История** операций с цветовой индикацией
- Кредитный рейтинг и общий долг в топбаре

### 3.8. Отчётность (Stats.exe)

- Детальная статистика прогресса, доходов, операций
- Визуализация показателей (гауги, списки)

### 3.9. Магазин (Store.exe)

- Покупка «приложений» / апгрейдов (базовая реализация)

### 3.10. ЭЦП и СКЗИ (Crypto.exe)

- Покупка USB-токена и драйверов (тематический модуль в духе 90-х/госуслуг)

### 3.11. Браузер (Browser.exe)

- Имитация браузера с адресной строкой, закладками и страницами:
  - home.cash, rabota.cash, office.market, zakazy.birzh, gos.cash и др.
- Навигация «назад / вперёд / обновить / домой»

### 3.12. Почта (Mail.exe)

- Папки: Входящие, Отправленные, Спам, Корзина, Черновики
- Непрочитанные, фильтры по ключевым словам
- Базовый UI почтового клиента в стиле Win95

### 3.13. Popup

- Компактный интерфейс расширения с доступом к ключевым действиям и состоянию

## 4. Структура проекта

Каждый файл и его роль:

| Файл | Назначение |
|------|------------|
| `manifest.json` | Manifest V3: имя, версия, popup, иконки, permissions (`storage`), background service worker |
| `background.js` | Service worker расширения (фон) |
| `shared.js` | **Ядро игры**: состояние, CONFIG, квесты, клики, тики, рынок, недвижимость, банк-логика тиков, сохранение/загрузка, утилиты |
| `win95.css` | Общий CSS-фреймворк эстетики Windows 95 (кнопки, окна, bevel, шрифты) |
| `fullpage.html` / `fullpage.css` / `fullpage.js` | Полноэкранный режим: рабочий стол, иконки, менеджер окон (WM), таскбар, панель метрик |
| `popup.html` / `popup.css` / `popup.js` | Всплывающее окно расширения |
| `bank.html` / `bank.css` / `bank.js` | Банк: депозиты, кредиты, ипотека, история, кредитный рейтинг |
| `casino.html` / `casino.css` / `casino.js` | Казино: слоты, рулетка, ставки, снижение выгорания |
| `invest.html` / `invest.css` / `invest.js` | Инвестиции: акции, портфель, недвижимость |
| `stats.html` / `stats.css` / `stats.js` | Отчётность и подробная статистика |
| `store.html` / `store.css` / `store.js` | Магазин приложений / апгрейдов |
| `crypto.html` / `crypto.css` / `crypto.js` | Модуль ЭЦП / СКЗИ (токен, драйверы) |
| `browser.html` / `browser.css` / `browser.js` | Внутриигровой «браузер» с сайтами и закладками |
| `mail.html` / `mail.css` / `mail.js` | Почтовый клиент |
| `README.md` | Краткое описание и установка |
| `update.txt` | Список идей улучшений и новых механик |
| `AGENTS.md` | Контекст проекта для агентов / ассистентов |
| `GAME_DESCRIPTION.md` | Этот документ — полное описание и дорожная карта |

**Примечание:** иконки расширения (`icons/icon16.png` и т.д.) указаны в манифесте, но в текущем снимке артефактов папки `icons` может не быть — её нужно добавить при сборке.

## 5. Дорожная карта развития

Приоритеты:

### Фаза 1 — Срочно (максимальный эффект, ближайшие итерации)

1. **Система достижений / ачивок**
   - Постоянные цели: «Первая покупка», «1000 кликов», «Банкрот», и т.п.
   - Окно «Достижения.exe» с прогрессом
   - Награды: кэш, фокус, редкие предметы

2. **Временные бустеры и коллекционные предметы**
   - Кэш-бэки, скидки, временное удвоение дохода
   - Карточки / бустеры с ограниченным временем действия

3. **Случайные кризисные события**
   - «Сгорел ноутбук», «Заказчик не заплатил» и т.п.
   - Выбор реакции (тратить деньги / терпеть)
   - Влияние на фокус, выгорание, кэш

4. **Полировка UX и баланса**
   - Звуки кликов и событий
   - Анимация загрузки в стиле Win95
   - Тонкая настройка аренды, долга, комбо, доходности

### Фаза 2 — Скоро (обогащение геймплея)

5. **Криптовалютная биржа**
   - 3–5 валют с высокой волатильностью
   - Кошелёк, комиссии
   - Майнинг (фокус / оборудование)
   - Аирдропы за активность

6. **Фондовый рынок 2.0**
   - Дивиденды, индексы, опционы (ставки на рост/падение)
   - Более богатые «новостные» события, влияющие на цены

7. **Рынок недвижимости с анимацией**
   - Колебания цен, перепродажа
   - Арендаторы → доп. доход
   - Улучшение объектов (ремонт → рост дохода)

8. **Автоматизация (скрипты)**
   - Покупка скриптов авто-клика (x1.5 / x2 / x3)
   - Расход энергии / обслуживание
   - Условные сценарии («если фокус < X — отдых»)

9. **Перки и навыки**
   - Древо прокачки: технический / коммуникативный / лидерский
   - XP за квесты → пассивные бонусы (меньше выгорания, больше фокуса)

10. **Бизнес-стартапы**
    - Своя кофейня / студия / агентство
    - Наём сотрудников (расширение стажёров)
    - Бизнес-циклы (кризисы и бумы)

### Фаза 3 — Потом (глубина и «живой мир»)

11. **Фриланс-биржа заказов**
    - Случайные заказы разной сложности
    - Рейтинг исполнителя, штрафы/бонусы

12. **Карьерный рост**
    - Фрилансер → Студия → IT-компания
    - Смена специализации, новые возможности

13. **Сюжетные миссии**
    - Сквозная история с диалогами и выборами
    - Несколько концовок (богат / сгорел / уехал на Бали)

14. **Игровые новости и сезонные события**
    - Новости влияют на рынки и экономику
    - Новогодние бонусы, летний отпуск, еженедельные челленджи

15. **Социальные / мультиплеерные элементы** (опционально)
    - Команда / гильдия
    - Обмен сохранениями, облачный прогресс
    - Мини-чат с NPC (консультанты, заказчики)

16. **Технические улучшения**
    - Экспорт / импорт сохранений
    - Облачная синхронизация
    - Расширенная статистика и графики (день / неделя / месяц)
    - «Кабинет трофеев», секретные достижения
    - Обои рабочего стола по уровню, кастомный курсор

## 6. Технический стек и ограничения

- **Язык:** чистый JavaScript (без фреймворков)
- **Стили:** CSS, общий `win95.css` + модульные стили
- **Хранение:** `chrome.storage.local` (+ localStorage fallback)
- **Архитектура:** shared core + модульные HTML/JS «программы», открываемые как окна
- **Целевая платформа:** Chrome / Chromium (Manifest V3)
- **Запуск fullpage:** рекомендуется через локальный HTTP-сервер (из-за iframe / путей)
