# 🚀 КЭШ.СТРИМ (CashStream)

**Веб-игра в жанре "продуктивный кликер" с элементами симулятора жизни фрилансера, выполненная в эстетике Windows 95.**

Вы — фрилансер-стартапер, начинающий путь с дешевым ноутбуком в антикафе. Ваша цель — построить финансовую империю, кликая по рабочим задачам, управляя ресурсами «Фокус» и «Кэш», и балансируя на грани выгорания. Сходите в казино, чтобы снять стресс, или наймите стажеров для пассивного дохода.

> **Текущая версия: MVP 1.0** (Кликер + Квесты + Казино)
> 
> Игра реализована как **Chrome-расширение (Manifest V3)** с общим состоянием через `chrome.storage.local`, что позволяет играть и в попапе, и в полноэкранном режиме без потери прогресса.

---

## 🧠 Главная концепция

Главный ресурс игры — **«Фокус»** (энергия кликов) и **«Кэш»** (игровая валюта). Но вместо скучного кликанья, вы «тапаете» для выполнения реальных рабочих задач. Механика **«Тап-Таска»** визуализирует на экране проекты, а ритмичные клики активируют режим **«Поток»** с комбо-множителем.

**Итоговый цикл игры:**
1.  **Работайте** — выполняйте квесты, кликая по задачам и зарабатывая Кэш.
2.  **Отдыхайте** — снимайте накопившееся «Выгорание» в мини-играх казино.
3.  **Инвестируйте** (в разработке) — вкладывайте прибыль в акции или недвижимость.
4.  **Прокачивайтесь** — нанимайте стажеров, покупайте улучшения и кастомизируйте интерфейс.

## 🕹️ Реализованный геймплей (MVP)

### 1. Симуляция рабочей деятельности (Кликер)
- **Рабочая зона:** Кликайте в центре экрана, чтобы зарабатывать Кэш. Каждый клик тратит «Фокус» и накапливает «Выгорание».
- **Режим «Поток»:** Серия быстрых кликов (быстрее ~0.9 с) активирует комбо-множитель до **x3** к заработку.
- **Выгорание:** При заполнении шкалы до 100% клики блокируются. Единственный выход — посетить казино «Перерыв» для сброса стресса.
- **Пассивный доход:** Наймите виртуальных стажеров, которые приносят Кэш каждую секунду, даже когда вы не кликаете.

### 2. Мини-квесты (Сюжетные цепочки)
Каждый квест — это история из 3 шагов, которая генерируется системой:
- **`tap`** — Набрать N кликов по рабочей зоне.
- **`find`** — Найти N иконок ❌ среди рабочих иконок в сетке 3×3 (визуальный поиск ошибок в ТЗ).
- **`puzzle`** — Собрать цены по возрастанию, чтобы отправить «коммерческое предложение».

Прогресс квестов сохраняется между сессиями.

### 3. Симулятор Казино («Перерыв»)
Раздел для отдыха и быстрого заработка, снижающий шкалу «Выгорания»:
- **Слот «Деловая встреча»:** Крутите барабан с иконками (Кейс, Визитка, Шампанское). Выпадение 3-х одинаковых дает временный бафф к доходу.
- **Рулетка «Биржа»:** Ставьте «Фокус» на красное/черное. Выигрыш удваивает Кэш и снижает Выгорание. Проигрыш увеличивает стресс, делая будущие задачи сложнее.

## 🎨 Тема оформления: «Офис 90-х»
Текущая визуальная оболочка выполнена в стиле ретро-ПК:
- **Интерфейс в стиле Windows 95:** бежевые окна с фасками, градиентные заголовки и кнопки.
- **Тикер кэша** под DOS-терминал.
- **Полноэкранный режим:** Рабочий стол с тремя перетаскиваемыми окнами (Задачи, Работа, Казино).

## ⚙️ Как запустить

1.  Откройте в браузере Chrome страницу `chrome://extensions`.
2.  Включите **«Режим разработчика»** (переключатель справа вверху).
3.  Нажмите **«Загрузить распакованное расширение»** и выберите корневую папку проекта `cashstream/`.
4.  В панели расширений появится иконка **«$»**. Нажмите на неё, чтобы открыть попап-версию.
5.  В попапе нажмите кнопку **«🖥️ Развернуть на весь экран»** для доступа к полному рабочему столу.

> **Важно:** Кошелёк, Фокус, Выгорание и Квест — общие для попапа, вкладки и окна казино. Всё состояние хранится в `chrome.storage.local`.
